# TapAtlas · The Radiotherapy Contour Atlas Generator

Create radiotherapy contour atlases from reference contours: navigable PDF and PowerPoint atlases built from DICOM planning CT + RTSTRUCT, registered MR/CT scans (REG), and RTDOSE/RTPLAN. Designed for clinical-trial protocol packs and trainee education.

Everything runs in the browser (Pyodide + pydicom); no files are uploaded.

**Open the app:** https://roresource.github.io/tapatlas/

*TapAtlas: from the Irish* tapa*, "quick".*

The earlier prototype is kept at https://github.com/ROResource/rt-dicom-pyodide-test.
